# WAMO

WAMO is an original mobile-first messaging web app with an iOS-inspired information architecture and a custom Liquid Glass visual system.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Vercel

Import the repository into Vercel. The project uses Vite and requires no backend.

## Notes

- Demo data is local-only.
- Messages and preferences are stored in localStorage.
- The service worker is registered in production/preview contexts.
- WAMO does not use WhatsApp source code, assets, branding, or proprietary files.
